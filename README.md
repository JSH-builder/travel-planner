# 🧳 함께 쓰는 여행 계획

여행을 **AI 추천으로 채우거나 직접 채우고**, 동행자와 **링크 하나로 함께** 방문 체크·사진·영상·지출을 기록한 뒤,
여행이 끝나면 **블로그 글과 여행 영상**으로 남기는 모바일 웹앱입니다. (PC에서는 모바일 화면 그대로 가운데에 보여요)

```
 [동행자 폰]  ─┐                          ┌─ 체크·사진·영상·지출·일기 (언제나 바로 저장)
 [내 폰/PC]   ─┼─▶ 웹 화면 (GitHub Pages) ─▶ Supabase (DB + 사진·영상 저장)
               │                          └─ AI 요청(추천·블로그)이 쌓이면
               │                             내 PC의 작업기가 내 Claude 구독(claude -p)으로 처리
```

## 화면 (아래 탭)

| 탭 | 하는 일 |
|---|---|
| 🏠 **개요** | 여행 대시보드: D-day/여행 중 Day n, **오늘 일정**, 방문·사진·지출·준비 진행률, 카테고리별 현황, 확정 예약 원문, 주의 사항, **추천 영상**, 여행지 사진 미리보기, 기록 만들기 |
| 📅 **일정** | 날짜 띠 + 날짜별 카드 (고정 일정, 가볼 곳, 사진, **오늘의 기록**). 여행 중엔 **오늘이 맨 위**, 지난 날은 아래 '지난 일정'으로. 여행 전·후엔 날짜순 |
| 📍 **스팟** | 📸사진 명소 · 🍜먹거리 · ☕카페 · 📍가볼 곳 · 🏛️랜드마크 · 🎡즐길거리 카드. **✓ 방문** 한 번으로 시간·누가 기록. 카드마다 사진·영상, 지도·사진 예시·유튜브. ＋로 직접 추가, ✨로 AI 추천 더 받기 |
| 🖼️ **앨범** | 직접 올린 것 + 스팟 카드·일정에서 올린 사진·영상이 날짜별로 자동으로 모임. 설명 쓰기·대표 사진 정하기 |
| 💰 **지출** | **총 지출 · 1인당** · 날짜별 · 분류별 (일정 비용 + 직접 기록 자동 합산), 현지 통화 → 원 자동 환산 |
| 🧳 **준비** | 출발 전 할 일 · 준비물 체크리스트, 비상 연락 |
| 🎞️ **기록** (개요·메뉴) | ✍️ **블로그 글**(AI가 방문·일기·사진으로 작성 → 사진 포함 복사 / 글만 복사 / 사진 한 번에 받기)<br>🎬 **여행 영상**(폰 안에서 자동 제작, 세로·가로, 배경음악 → 저장·앨범·**OpenCut**에서 더 편집) |

모든 칸은 **누르면 고치고, 자동 저장**됩니다 (여행 제목 포함). AI 결과는 항목으로 **추가만** 되고, 직접 고친 내용을 덮어쓰지 않습니다.

## 🖼️ 스팟 사진·정보 모으기 (작업기가 켜져 있을 때)

| 스팟 | 하는 일 |
|---|---|
| **AI 추천으로 담긴 곳** | 담기는 즉시 대기열에 들어가요 → 웹 이미지 검색(네이버 블로그·트리플·여행 사이트·SNS 등)으로 **사진 최대 8장** + 웹 조사로 **메뉴·최신 가격·1인 가격대·운영시간·휴무·비용·주의사항** 정리 |
| **직접 찾은 곳** | 스팟 상세 → **내가 찾은 링크**에 블로그·인스타·네이버/구글 지도 링크를 **여러 개** 넣으면, 링크 속 사진을 뽑고 본문을 요약해 같은 형식으로 정리 (먹거리=주로 시키는 메뉴, 즐길거리=사람들이 즐기는 것, 랜드마크=왜 가 봐야 하는지·운영시간) |

- 스팟 탭 위 **'사진·정보가 없는 n곳 채우기'** 로 예전에 담은 스팟도 한 번에 채울 수 있어요.
- 사진은 내 Supabase 저장소에 줄여서 저장되고, 사진마다 출처 사이트가 표시돼요. 잘못 들어온 사진은 사진을 눌러 **삭제**, 마음에 드는 사진은 **대표 사진으로**.
- 인스타그램·페이스북·틱톡처럼 로그인이 필요한 곳은 공개 미리보기(대표 이미지·설명)까지만 읽혀요. 부족한 내용은 같은 장소를 웹에서 찾아 보충해요.
- 개인 여행 계획용(비상업)으로만 쓰세요. 다른 사람 사진이므로 앱 밖으로 다시 게시하지 마세요.

## 📺 유튜브에서 본 곳 담기
- 스팟 탭 위 **'유튜브'** (또는 메뉴 ⋯) → 브이로그·맛집 영상 링크를 한 줄에 하나씩 (최대 5개)
- 작업기가 **제목 · 설명란 · 자막(스크립트)** 을 읽어서
  - 영상 요약 · 핵심 정보 · 꿀팁 → 홈의 **'유튜브에서 본 것'** 에 카드로 쌓임
  - 영상에 나온 장소 → **스팟으로 담김** (영상에서 말한 메뉴·가격·팁도 메모로) → 이어서 사진·메뉴·가격·지도 위치 자동 채우기
- 자동 자막은 받아쓰기 오류가 많아서, 장소 이름은 설명란·웹 검색으로 확인한 것만 담아요. 자막이 꺼진 영상은 제목·설명란으로만 정리해요.

## 🗓️ 일정 짜기
- **일정 탭**: 하루가 시간순 타임라인으로 보여요 (정해진 일정 + 시간을 정한 스팟). 사이사이 **이동 시간**과 '길찾기' 링크, 빠듯하면 주황색 경고.
- **＋ 일정 추가**: 이름 · 시작/끝 시간 · **장소**(넣으면 앞뒤 이동 시간 계산) · 메모. 누르면 언제든 고치기·삭제.
- **스팟 → '일정에 넣기'**: 날짜만 고르면 그날 일정 사이 빈 시간 · 이동 거리 · 영업시간 · 어울리는 시간대(식사·야경 등)를 보고
  추천 시간이 떠요 → **등록** 한 번. 마음에 안 들면 시간 직접 입력, 또는 시간 없이 날짜만.
- **일정마다 비용**: 타임라인 각 줄의 '＋ 비용'(또는 스팟 상세 '이 일정 비용')에 원·현지 통화로 넣으면 **지출에 자동으로 합산**돼요.
  일정을 지우면 그 비용도 같이 빠지고, 날짜를 옮기면 지출 날짜도 따라가요.
- **자동 할 일**: 스팟을 일정에 넣으면 필요한 할 일이 자동으로 생겨요 — 예약이 필요한 곳은 '예약하기', 현금만 받는 곳은 '현금 준비',
  사전 구매가 필요한 곳은 '티켓 미리 사기'. 일정에서 빼면 (완료하지 않은 것은) 자동으로 지워져요.
- 이동 시간은 OpenStreetMap(무료)으로 계산한 **추정값**이에요. 정확한 경로는 추천 카드의 **'구글 길찾기'** 로 확인하세요.
  (구글 길찾기 API는 결제 계정이 필요해서 쓰지 않아요)

## ✈️ 오프라인 모드 (해외에서 데이터가 끊겨도)
- 한 번 연 여행은 폰에 저장돼서, 연결이 없어도 일정·스팟·상세 정보·지출이 그대로 보여요 (위에 '오프라인' 띠 표시).
- **출발 전 와이파이에서 메뉴(⋯) → '오프라인용으로 저장'** 을 한 번 누르면 사진까지 미리 받아 둬요.
- 오프라인에서도 **방문 체크 · 스팟 수정 · 새 스팟 · 지출 기록 · 하루 기록 · 사진 설명**은 할 수 있고, 연결되면 자동으로 올라가요.
- 사진·영상 올리기, AI 요청, 링크 정리는 연결이 필요해요.

## 😴 Supabase 일시정지 방지
무료 Supabase는 7일 동안 요청이 없으면 멈춰요. GitHub Actions(`.github/workflows/keepalive.yml`)가 **매일 아침 한 번** 가볍게 접속해서 깨워 둬요.
실패하면 GitHub가 메일로 알려 줘요 → Supabase 대시보드에서 'Restore'를 누르면 돼요.

## 처음 설정 (소유자, 한 번만)

1. **설치**: `설치.bat` 더블클릭 → 터미널에서 `claude` 실행해 Claude 구독 계정으로 로그인
2. **Supabase**: 가입 → New project (지역 Seoul) → **SQL Editor**에 `supabase/schema.sql` 전체 붙여넣고 Run
3. **연결**: `연결 설정.bat` → Project URL · publishable 키 붙여넣기 → 나오는 **소유자 키** 보관
4. **웹 올리기**: GitHub 공개 저장소에 올리고 Settings → Pages → `main` / `/docs`
5. **사용**: `여행계획 작업기 실행.bat` 켜 두기 → 웹 화면에서 소유자 로그인 → ＋ 새 여행 → 🔗 공유 링크를 동행자에게

### 업데이트할 때 (v1 → v2 포함)
`supabase/schema.sql`을 SQL Editor에서 **다시 한 번 Run** (여러 번 실행해도 안전, 기존 여행 유지).
작업기를 켜면 예전 형식 여행이 새 형식(스팟·일정·준비물 항목)으로 **자동 변환**됩니다.

### ▶️ YouTube 영상 (선택)
- **키 없이**: AI가 고른 검색어가 카드로 보이고, 누르면 YouTube 검색 결과가 열려요.
- **키를 넣으면**: 작업기가 실제 영상을 찾아 썸네일과 앱 안 재생으로 보여 줘요.
  1. [Google Cloud 콘솔](https://console.cloud.google.com/)에서 프로젝트 만들기 → **YouTube Data API v3** 사용 설정
  2. 사용자 인증 정보 → API 키 만들기 → (권장) 키 제한: YouTube Data API v3만
  3. `.env`에 `YOUTUBE_API_KEY=발급받은키` 한 줄 추가 → 작업기 다시 실행
  - 이 키는 작업기(내 PC)만 쓰고 웹에는 올라가지 않아요.
