# 🧳 함께 쓰는 여행 계획

목적지·날짜·취향을 넣으면 Claude가 웹을 조사해 **여행 계획 초안**을 만들고,
**링크 하나로 동행자와 함께** 체크하고 메모·사진을 남기고 지출을 기록하는 앱입니다.

## 이 앱을 어디까지 믿어도 되나

| 믿어도 되는 것 (사용자가 입력한 데이터) | 확인이 필요한 것 (AI 초안) |
|---|---|
| **확정 예약 원문** — 입력한 그대로 저장·표시, AI가 바꾸지 못함 | 항공·숙소·예약 표 (**AI 정리본** 표시) — 원문과 다르면 원문이 맞음 |
| **총예산·통화·환율, 실지출** — 직접 입력한 값으로 잔액 계산 | 항목별 예산 (AI 추정치) |
| **체크·메모·사진** — 항목 *이름* 기준으로 저장 (재생성해도 다른 항목에 옮겨 붙지 않음) | 장소·맛집·행사·가격 — **✓ 확인됨**(이번 조사에서 웹 확인 + 출처 링크) / **미확인**(AI 기억·추측) 으로 구분 표시 |
| | 날짜별 갈 곳 목록 — 같은 지역끼리 묶은 것일 뿐, 이동 시간은 **🗺️ 구글 지도로 경로 보기**에서 확인 |

> 예약·결제·운영시간은 출발 전에 공식 사이트에서 꼭 다시 확인하세요. '확인됨'도 조사 시점 기준입니다.

```
 [동행자 폰/PC]  ─┐                         ┌─ 계획 생성·수정 요청이 쌓임
 [소유자 폰/PC]  ─┼─▶ 웹 화면 (GitHub Pages) ─▶ Supabase (DB + 사진)
                  │                         └─▶ 소유자 PC의 작업기가 가져가서
                  │                              내 Claude 구독(claude -p)으로 처리 후 결과 저장
```

## 💸 비용과 데이터

추가 결제는 없지만, **사용량 제한은 있습니다.**

| 구성 | 무료 범위 |
|---|---|
| AI 계획 생성 | 소유자의 Claude 구독 (`claude -p`, API 키 사용 안 함). **구독 사용량이 차감**되며, 검색 깊이·모델(Opus)에 따라 더 많이 씀. 한도에 걸리면 잠시 후 다시 시도 |
| Supabase | 무료 플랜: DB 500MB, 사진 저장 1GB (사진은 올릴 때 자동으로 줄여서 저장) |
| GitHub Pages | 공개 저장소 무료 호스팅 |

> ⚠️ Supabase 무료 프로젝트는 **7일간 아무도 안 쓰면 일시 정지**됩니다. 대시보드에서 Restore를 누르면 다시 켜집니다 (데이터 유지).

- 🔒 **데이터 전송**: 새 여행·수정 요청 때 입력한 내용(목적지, 동행, 예약 메모 등)이 계획 작성을 위해 **Claude(Anthropic)로 전송**됩니다. 여권번호·카드번호 같은 민감 정보는 넣지 마세요.
- 체크·메모·사진·지출은 **Supabase**(내 프로젝트)에 저장되고, 공유 링크를 아는 사람은 볼 수 있습니다.

## 💾 백업

- 작업기가 켜져 있으면 **6시간마다 전체 여행을 `backups/` 폴더에 JSON으로 자동 백업**합니다 (최근 30개 보관).
- 여행 화면의 **⬇️ 내보내기 (JSON)** 로 언제든 한 여행을 통째로 내려받을 수 있고, **🖨️ 인쇄 / PDF** 로 종이·PDF 보관도 됩니다.

## ⏹️ 진행 상황과 취소

- AI가 일하는 동안 화면에 **실시간 진행 상황**(예: `🔎 웹 검색 3회째: 후쿠오카 야타이 운영시간`)이 보입니다.
- **취소** 버튼을 누르면 작업기가 몇 초 안에 멈추고, 수정 중이었다면 기존 계획이 그대로 유지됩니다.
- 요청은 대기열로 하나씩 처리되므로 여러 사람이 동시에 눌러도 겹치지 않습니다.

## 👥 누가 무엇을 할 수 있나

| | 소유자 (소유자 키 로그인) | 동행자 (공유 링크) |
|---|---|---|
| 여행 만들기·삭제, 내 여행 목록 | ✅ | — |
| 계획 보기, 체크, 실지출 입력 | ✅ | ✅ |
| 메모·사진 추가/삭제, 앨범 | ✅ | ✅ |
| AI에게 수정 요청 ("2일차 비 오는 날 버전으로") | ✅ | ✅ (소유자 PC 작업기가 처리) |

- 링크를 아는 사람만 그 여행에 들어갈 수 있습니다 (추측할 수 없는 주소). 링크는 믿을 수 있는 사람에게만 보내세요.
- AI 생성·수정은 **소유자 PC에서 작업기가 켜져 있을 때** 처리됩니다. 꺼져 있으면 대기했다가 켜지면 처리됩니다. 체크·메모·사진은 작업기와 상관없이 언제나 됩니다.

## 처음 설정 (소유자, 한 번만)

### 1. 설치
`설치.bat` 더블클릭 → Python·패키지·Claude Code 설치. 그다음 터미널에서 `claude`를 한 번 실행해 **Claude 구독 계정으로 로그인**.

### 2. Supabase 프로젝트 만들기 (5분)
1. [supabase.com](https://supabase.com) 가입 → **New project** (이름 아무거나, 지역 `Northeast Asia (Seoul)`, 비밀번호는 아무거나 저장)
2. 왼쪽 메뉴 **SQL Editor** → **New query** → `supabase/schema.sql` 내용 전체 붙여넣기 → **Run**
3. **Project Settings → Data API**에서 `Project URL`, **API Keys**에서 `publishable` 키(또는 `anon` 키) 복사

### 3. 연결
**`연결 설정.bat`** 더블클릭 → 뜨는 창에 Project URL과 publishable 키를 붙여 넣기.
(채팅·메신저 등 다른 곳에 붙여 넣을 필요 없음. secret 키를 넣으면 거부합니다)
- `.env`(비밀, Git에 안 올라감)와 `docs/config.js`(공개용)가 만들어지고 **소유자 키**가 출력됩니다. 잘 보관하세요.
- 예전 로컬 앱(`data/trips`)의 여행이 있으면 자동으로 복사됩니다.

### 4. 웹 화면 올리기 (GitHub Pages)
1. GitHub에 **공개(Public)** 저장소를 만들고 이 폴더를 올립니다. (`.env`, `data/`는 `.gitignore`로 제외됨)
2. 저장소 **Settings → Pages → Branch: `main` / 폴더: `/docs`** → Save
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/` 에서 열립니다.

> GitHub에 올리기 전에는 `여행계획 화면 열기 (내 PC).bat`으로 내 PC에서 확인할 수 있습니다.

### 5. 사용
1. `여행계획 작업기 실행.bat`을 켜 둡니다.
2. 웹 화면 오른쪽 위 **소유자** → 소유자 키 입력 → **+ 새 여행**
3. 계획이 완성되면 **🔗 공유 링크 복사** → 동행자에게 카톡으로 전송

## 다른 사람이 자기 버전을 쓰려면

이 저장소를 받아(Fork 또는 다운로드) 위 **처음 설정**을 똑같이 하면 됩니다.
각자 **자기 Claude 구독**과 **자기 Supabase 프로젝트**를 씁니다. (내 구독으로 남의 여행을 만들어 주는 것은 Claude 구독 약관상 허용되지 않습니다)

## 구조

| 경로 | 역할 |
|---|---|
| `docs/` | 웹 화면 (HTML·CSS·JS, 빌드 불필요). GitHub Pages가 이 폴더를 올림 |
| `supabase/schema.sql` | DB 테이블, 접근 함수, 사진 저장소 정책 |
| `travel_planner/worker.py` | 작업기: 요청을 가져와 `claude -p`로 처리 |
| `travel_planner/planner.py` | Claude 프롬프트·실행 (생성 / 수정) |
| `travel_planner/models.py` | 계획 데이터 구조 |
| `prompts/system.md` | Claude 작성 규칙. 정리 스타일을 바꾸려면 여기를 수정 |
| `tools/mock_supabase.py` | 개발용 가짜 Supabase (실제 프로젝트 없이 테스트) |

디자인은 `docs/app.css` 맨 위 `:root` 색상 토큰부터 바꾸면 됩니다. 다크 모드는 기기 설정을 따릅니다.

### 개발용: Supabase 없이 테스트
```powershell
.\.venv\Scripts\python.exe tools\mock_supabase.py          # 가짜 서버 (메모리, 끄면 사라짐)
.\.venv\Scripts\python.exe -m travel_planner setup --url http://127.0.0.1:54321 --key dev
```
테스트가 끝나면 진짜 Supabase 주소로 `setup`을 다시 실행하세요.
